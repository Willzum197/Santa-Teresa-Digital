# 🇻🇪 Santa Teresa al Día

App con información, cultura y fe de Santa Teresa del Tuy, Estado Miranda, Venezuela.

## 📋 Secciones

- 📰 Noticias
- 🏪 Directorio de negocios
- 💭 Reflexiones
- 📜 Crónicas
- 🎬 Multimedia
- ⚠️ Denuncias
- 👥 Personajes
- ⚖️ El Crimen No Paga
- 🩺 Hablando con tus doctores (200+ enfermedades)
- 🛍️ Willian'Variedades
- 💬 Opiniones

## 🏗️ Tecnologías

- Streamlit (Frontend)
- Python 3 (Backend)
- Supabase (Base de datos)
- GitHub (Repositorio)
- Streamlit Cloud (Hosting)
